# Маршрутный центр

Локальное приложение на JDK 21. В одной папке выполните:

```powershell
javac -encoding UTF-8 RoutePlanner.java RoutePlannerTest.java Main.java
java RoutePlannerTest
java Main
```

Тесты печатают OK. Откройте http://127.0.0.1:8090. Измените цену C→B, нажмите «Рассчитать маршрут». При 1 ответ 6, при 2 и 3 — 7. Остановка: Ctrl+C. Если порт занят, проверьте свою ранее запущенную копию.

Модель: DAG в порядке A,C,B,D. Рёбра A→C=2, A→B=4, A→D=12, C→B=w, C→D=7, B→D=3. Веса 1–99. При равенстве возвращается один оптимальный путь.

RoutePlanner.java выполняет чистый расчёт; RoutePlannerTest.java сравнивает его с перебором на 100 воспроизводимых графах и проверяет границы. Main.java принимает GET на /route?w=1; неверный параметр получает 400, неизвестный путь 404, другой метод 405. Сервер слушает только 127.0.0.1. Это учебное локальное приложение; внешнее размещение требует отдельной подготовки.

Для защиты: нарисуйте граф, предскажите результат при изменении веса, покажите контрпример жадному выбору и объясните топологический порядок. Авторское расширение добавляйте после прохождения базовых тестов.
