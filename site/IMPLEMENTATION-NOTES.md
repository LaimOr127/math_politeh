# Состояние реализации

Актуальное описание изменений находится в docs/REVIEW.md, архитектура — в docs/ARCHITECTURE.md. Работают восемь уроков с тремя вопросами, локальный прогресс, сохранение темы, знакомство и кабинет преподавателя с серверной проверкой файлов.

Сайт запускается npm start. Статическая раздача всего репозитория не поддерживается. Данные курса генерируются из lessons/content; после изменения выполняются npm run sync:site и npm run check.
