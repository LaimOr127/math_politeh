# Проверка сайта

## Автоматически

`npm run check` проверяет, что повреждённый прогресс не используется, миссия начисляет не больше одной звезды и порядок строк проверяется точно.

## Вручную

1. Пройти первую миссию с неверным и верным ответом.
2. Убедиться, что вторая миссия открылась и первая не получила вторую звезду при повторной проверке.
3. Пройти миссию с функцией, включая удаление последней выбранной строки.
4. Сбросить прогресс и убедиться, что закрылись все миссии, кроме первой.
5. Повторить путь только клавиатурой и при включённом `prefers-reduced-motion`.
