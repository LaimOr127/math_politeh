# Проверка сайта

`npm run check` проверяет актуальность course.js, доменные правила, прогресс и миграции, настройки темы, согласованность вопросов, Python-примеры и HTTP-доступ преподавателя. PYTHON переопределяет интерпретатор. UTF-8 задаётся явно, CRLF нормализуется.

## В браузере

1. При первом посещении проверить Tab/Shift+Tab внутри знакомства, Escape и повторное открытие через «Помощь».
2. Сменить тему и перезагрузить: знакомство не должно повториться, тема сохраняется.
3. Проверить ответ без выбора, неверный и верный варианты. Повтор не выдаёт лишнюю деталь.
4. После первого верного ответа перезагрузить тест: должен открыться второй вопрос. Завершить три вопроса и открыть второй урок.
5. Сбросить прогресс: доступен только первый урок, тема сохраняется.
6. Повторить путь клавиатурой, при reduced motion и ширинах 375/1280 пикселей.
7. В кабинете ввести неверный код, затем lesson или свой код. Проверить скачивание и выход. Прямой URL файла после выхода должен вернуть 401.
8. После входа перезагрузить кабинет: материалы восстанавливаются без ввода кода.

PPTX/DOCX дополнительно отрисовываются. Успешные тесты не заменяют визуальную и методическую проверку.
