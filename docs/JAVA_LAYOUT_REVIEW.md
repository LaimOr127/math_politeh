# Проверка схем и подраздела практики Java

Дата: 12 ноября 2026 года.

## Исправления

В уроках растровая схема имела атрибуты 1600 × 900, но CSS изменял только ширину. Класс lesson-diagram теперь задаёт height:auto и максимальную ширину 1100 px. SVG учебного графа сохраняет отдельный класс map. Исходные width/height у PNG оставлены для стабильного размещения до загрузки.

Лаборатория перенесена из обзора и занятий в самостоятельный маршрут /java/#graph-lab. Она доступна из пункта «Практика» и по ссылкам из занятий 6–10. Есть собственные h1, title, активная ссылка, фокус основного содержимого после перехода и ссылки к связанным занятиям.

В шести схемах исправлены точки соединения: компиляция, DAG, BFS, взвешенный граф, проверка данных, HTTP. Подписи горизонтальных стрелок центрируются над линией, вертикальных — располагаются справа. В HTTP запрос и ответ проходят внутри высоты блоков двумя рядами.

## Материалы

Все 10 презентаций собраны и отрисованы: 150 слайдов. Проверены структура пакетов, геометрия, шрифты и повторный импорт. Просмотрены обзоры всех слайдов и обе версии десяти схем. В поставку включены шесть изменённых PPTX; презентации 2–5 сохранены без изменений.

В общем научно-методическом DOCX заменены ровно шесть встроенных PNG. Все остальные части ZIP, включая текст, стили, размеры рисунков, поля, подписи, настройки и связанное содержание, совпадают с предыдущей проверенной версией побайтно. Десять сценариев преподавателя не изменены: рисунки в них не встроены. ZIP и MATERIALS_MANIFEST.json пересобраны.

Ограничение проверки Word: повторная постраничная отрисовка в этой сессии не выполнена. В текущем Windows runtime нет комплектного LibreOffice, а навык documents запрещает подменять его установленной настольной версией. Проверка опирается на сохранение всех частей документа, определяющих вёрстку, неизменные размеры PNG, визуальную проверку новых рисунков и прежнюю проверенную пагинацию. Новую полную отрисовку DOCX это не заменяет.

## Проверки

- npm run check: 28 тестов, включая компиляцию Java, эталонные DAG, HTTP-контракт, защиту материалов и согласованность Office.
- browser_check.cjs: 354 проверки; все 10 уроков, отдельная лаборатория, ширины 320/360/768/1440, пропорции всех изображений, прогресс, ошибки, повторы, клавиатура, сброс и кабинеты преподавателя.
- Две проверки с намеренно устаревшими изображениями в временных копиях: PPTX и DOCX отклонены новым verify_materials.py.
- Новый верификатор сверяет встроенную диаграмму каждого слайда с его каноническим PNG, все 11 рисунков пособия — с печатными PNG, а ZIP — с финальными файлами.
- Встроенный preview дважды завершился PreviewAutomationTimeoutError; визуальная проверка сайта выполнена по снимкам Playwright.
- Проверены изменённые вызовы, маршрутизация и обновление навигации по ponytail-review. Необоснованные зависимости и новые архитектурные слои не добавлены.
- Проверка безопасности изменений: DOM строится через textContent; хеш маршрута выбирается из фиксированных значений; eval, innerHTML, новые внешние ресурсы и изменение границы доступа отсутствуют. Защищённые загрузки проверяются серверными тестами.
- Проверка интерфейса: семантические ссылки и формы, подписи полей, aria-current, фокус, reduced motion, отсутствие горизонтального переполнения. Тёмное оформление Java соответствует заданию; обе темы существующих кабинетов также проверены.

Результат ревью: блокирующих замечаний в изменённом поведении не найдено. Локальные снимки, отчёты и временные копии исключены из Git.
