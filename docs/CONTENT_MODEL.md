# Модель содержания урока

Общие источники — `lessons/content/lesson-01.json` … `lesson-08.json`. `course.js` генерируется `npm run sync:site`; ручное редактирование запрещено.

## Поля

- id — номер 01–08, missionId — стабильный идентификатор маршрута.
- title, concept, goal, analogy — тема и методические ориентиры.
- code, stdin, output — основной пример, ввод и точный stdout Python.
- practice, solution, solutionStdin, solutionOutput — работа и решение.
- slides — 18 этапов с общим временем 45 минут.
- exercises — три общих вопроса сайта и Word-пособий.
- web.title, web.sections — название и подробные объяснения ученику.
- scientificSections — изложение темы в научном стиле для сводного пособия.

## Слайд

Обязательны title, minutes, body, teacher, action, question, answer, animation. Код и вывод добавляются для демонстрации. Намеренно ошибочный код применяется в разборе ошибок; основной пример и решение обязаны исполняться.

Вывод отдельного слайда может содержать пояснение «При вводе 3: 4». Точные исполняемые эталоны находятся на уровне урока. stdin и stdout показаны отдельно: перенаправленный ввод не печатает эхо клавиатуры. Сборщик не выдаёт текстовый результат за скриншот терминала.

## Вопрос

id — стабильный идентификатор прогресса. Choice использует options из пар идентификатор/текст и answer с правильным идентификатором. feedback.correct объясняет результат, feedback.incorrect даёт подсказку. Доменный слой также поддерживает order для прежних данных; текущий интерфейс использует три choice-вопроса.

Менять смысл опубликованного вопроса без смены идентификатора не следует. Несовместимое изменение требует миграции ProgressStore и проверки старых результатов.

| Идентификатор | Урок | Навык |
| --- | --- | --- |
| hello | 1 | print и последовательность |
| variables | 2 | переменная и строка |
| input | 3 | input и int |
| condition | 4 | if и else |
| loop | 5 | for и range |
| list | 6 | индексы и append |
| function | 7 | определение и вызов |
| project | 8 | игра с одной попыткой |

После изменения JSON выполняются синхронизация, тесты примеров и пересборка материалов. PPTX/DOCX дополнительно отрисовываются. Другие короткие примеры той же темы допустимы, основной пример и вопросы должны совпадать во всех форматах.
