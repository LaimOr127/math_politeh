# Модель содержания урока

Общие источники — `lessons/content/lesson-01.json` … `lesson-08.json`. `course.js` генерируется `npm run sync:site`; ручное редактирование запрещено.

## Поля

- id — номер 01–08, missionId — стабильный идентификатор маршрута.
- title, concept, goal, analogy — тема и методические ориентиры.
- code, stdin, output — основной пример, ввод и точный stdout Python.
- practice, solution, solutionStdin, solutionOutput — работа и решение.
- slides — 18 этапов с общим временем 45 минут.
- exercises — три общих вопроса сайта и Word-пособий.
- web.title, web.sections — название и подробные объяснения ученику.
- scientificSections — изложение темы в научном стиле для сводного пособия.

## Слайд

Обязательны title, minutes, body, teacher, action, question, answer, animation. Код и вывод добавляются для демонстрации. Намеренно ошибочный код применяется в разборе ошибок; основной пример и решение обязаны исполняться.

Вывод отдельного слайда может содержать пояснение «При вводе 3: 4». Точные исполняемые эталоны находятся на уровне урока. stdin и stdout показаны отдельно: перенаправленный ввод не печатает эхо клавиатуры. Сборщик не выдаёт текстовый результат за скриншот терминала.

## Вопрос

id — стабильный идентификатор прогресса. Choice использует options из пар идентификатор/текст и answer с правильным идентификатором. feedback.correct объясняет результат, feedback.incorrect даёт подсказку. Доменный слой также поддерживает order для прежних данных; текущий интерфейс использует три choice-вопроса.

Менять смысл опубликованного вопроса без смены идентификатора не следует. Несовместимое изменение требует миграции ProgressStore и проверки старых результатов.

## Единое иллюстрированное пособие

`scientific-methodical-guide.docx` включает научное описание, все восемь тем с программами и решениями, вопросы с ответами, планирование и полные сценарии всех 144 слайдов. Разговорная речь преподавателя сохраняется в приложении В как первичный методический материал; основной текст использует научный стиль. Результаты педагогического эксперимента не выдумываются.

`build_illustrations.py` создаёт 11 авторских схем в `lessons/illustrations/`; значения переменных, диапазона и списка извлекаются из тех же исходных программ. Схемы поясняют содержание и архитектуру и не изображают несуществующие снимки экрана. `build_documents.py` встраивает изображения с подписями, ссылками и альтернативным текстом.

Для сводного пособия применяются положения ГОСТ 7.32–2017 о странице и структуре, а для списка источников — ГОСТ Р 7.0.100–2018. Проверяются A4, поля 30/15/20/20 мм, Times New Roman 14 pt, полуторный интервал, абзац 1,25 см и отсутствие номера на титульной странице. Таблицы и код используют читаемый уменьшенный кегль. Реквизиты учреждения и автора задаются отдельно при адаптации к требованиям вуза.

`update_scientific_contents.py` получает номера страниц из фактической отрисовки PDF, заполняет редактируемое поле содержания и внутренние ссылки. Повторная отрисовка и режим `--check` подтверждают актуальность нумерации. Не публикуйте промежуточный DOCX до этого шага.

| Идентификатор | Урок | Навык |
| --- | --- | --- |
| hello | 1 | print и последовательность |
| variables | 2 | переменная и строка |
| input | 3 | input и int |
| condition | 4 | if и else |
| loop | 5 | for и range |
| list | 6 | индексы и append |
| function | 7 | определение и вызов |
| project | 8 | игра с одной попыткой |

После изменения JSON выполняются синхронизация, тесты примеров и пересборка материалов. PPTX/DOCX дополнительно отрисовываются. Другие короткие примеры той же темы допустимы, основной пример и вопросы должны совпадать во всех форматах.

## Содержание Java для 10–11 классов

Отдельный источник java-course/content/course.json содержит метаданные, настройку среды, источники и 10 lessons. Идентификаторы java-01…java-10 не пересекаются с Python. Урок содержит title/subtitle/hook/goal, три theory с полным текстом, code/stdout, diagram/trace, три tasks, lab/solution, trap, project/defense/homework/ege и 15 slides. Первые 7 слайдов занимают 45 минут, оставшиеся — ещё 45.

Задание tasks имеет id,prompt,answer,hint,explanation. Это числовая самопроверка; ход решения проверяет преподаватель. Идентификаторы прогресса меняются при несовместимой смене смысла задания. Отдельные extraExamples задают полный файл, stdin/stdout и необходимые файлы входных данных. sync.mjs материализует все примеры и проверяет их актуальность.

Слайд хранит полный body, сокращённый screen, teacher, question, answer, minutes и необязательный code/diagram. Полный teacher попадает в заметки PPTX и сценарий Word; основной текст пособия использует научное изложение, приложение А содержит методические сценарии. В публичный модуль slides не включается.

ФИПИ 2027: логика, обработка данных и анализ DAG используются как тематические ориентиры; курс не заявляет полного охвата ЕГЭ. Оптимальный путь и подсчёт путей соответствуют новой тематике задания 23. Модель итогового приложения явно ограничена DAG и положительными весами 1–99.

Лаборатория графов Java открывается из блока «Практика» по `#graph-lab`. Упоминания лаборатории в заданиях относятся к этому подразделу; изменять последовательность уроков или их ответы не требуется. Схемы компиляции, DAG, BFS, взвешенного графа, контракта и HTTP синхронно обновлены на сайте, в PPTX и общем пособии. Проверка Office сравнивает байты встроенных иллюстраций с финальными PNG.
