# Контентная модель миссии

Каждая миссия связана с одним уроком и содержит: `id`, `lesson`, `title`, `concept`, `story`, `objective`, `code`, `output`, `illustration`, `challenge` и `feedback`.

`challenge.type` поддерживает:

- `choice`: ребёнок выбирает один результат или фрагмент кода.
- `order`: ребёнок расставляет строки в нужной последовательности.

Каждая запись обязана включать правильный ответ, объяснение правильного ответа и понятную подсказку для неправильного. Код и `output` должны быть запущены в VS Code до публикации в учебных материалах.

| Миссия | Урок | Навык |
| --- | --- | --- |
| `hello` | 1 | `print()` |
| `variables` | 2 | переменные и строки |
| `input` | 3 | числа и `input()` |
| `condition` | 4 | `if` / `else` |
| `loop` | 5 | цикл `for` |
| `list` | 6 | списки |
| `function` | 7 | функции |
| `project` | 8 | итоговая консольная игра |

## Текстовые уроки сайта

`site/src/data/course.js` — источник текущих восьми текстовых уроков. Каждый содержит `id`, `title`, `concept`, `goal`, массив `sections` (заголовок, абзацы и необязательные `code`/`output`) и три проверочных `exercises`. Вопрос содержит варианты, идентификатор ответа и объяснения для правильного и ошибочного ответа. `Mission` проверяет структуру при загрузке. Старый `missions.js` больше не используется интерфейсом; отдельное пособие и презентации пока имеют самостоятельные источники и требуют синхронизации.

## Презентации и сценарии преподавателя

`lessons/content/lesson-01.json` … `lesson-08.json` содержат сценарии восьми уроков. Каждый слайд включает продолжительность, текст объяснения, действия преподавателя, вопрос и ожидаемый ответ; сумма продолжительностей — 45 минут. Из этих же данных собираются презентации и документы преподавателя. Основной пример и решение сопровождаются входными данными и полным ожидаемым выводом, включая приглашение `input()`. `site/tests/lesson-materials.test.js` проверяет структуру, тайминг и выполнение этих примеров. Для запуска проверки нужен Python 3; путь к нему можно указать переменной `PYTHON`.

Текстовые уроки сайта и материалы презентаций пока хранятся отдельно: при изменениях следует проверять оба источника. Наличие схемы или кадра в слайде не означает, что готово пошаговое пособие по установке VS Code.
