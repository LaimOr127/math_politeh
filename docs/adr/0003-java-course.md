# ADR 0003 Самостоятельный курс Java

Курс Java для 10–11 классов хранится в java-course/content/course.json. Из него собираются публичный модуль site/java/course.js, 10 презентаций, 10 сценариев преподавателя и научное пособие. Python и его идентификаторы сохраняются.

Сайт /site/java/ использует DOM API без исполнения кода ученика. ProgressStore принимает необязательный ключ; Java использует java-orbit-progress. Данные остаются в браузере. Все занятия доступны для чтения, отметки проверки открываются последовательно. Числовые ответы не доказывают самостоятельность; объяснение и защита оцениваются преподавателем.

Карта использует направленный DAG A,C,B,D. В Java проекте один проход по топологическому порядку, в интерактивной лаборатории чистая функция Дейкстры; обе реализации проверяются на одной карте. Цена линии 1–99; публичный учебный Java HttpServer привязан только к loopback и не включается в сервер курса.

Генераторы Office используют ранее установленный внешний Codex runtime и Python DOCX. Зависимостей времени выполнения сайта не добавляется. Пользователь требует сохранять файлы локально и в Git, поэтому презентации поставляются PPTX через существующий файловый конвейер.

Защищённый каталог получает отдельное поле javaCourse, чтобы прежние lessons/guides и 18 файлов Python сохранили контракт. Файлы Java выдаются по точному списку. Архив содержит проверенные финальные материалы и исходники проекта.
