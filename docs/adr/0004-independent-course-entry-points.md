# ADR 0004 Независимые курсы под одним адресом

Пользователь размещает ссылки на Python и Java в разных разделах основного сайта. Курсы должны открываться напрямую на одном origin без поддоменов и переходов между ними.

Выбраны `/python/` и `/java/`, кабинеты — `<курс>/teacher/`. URL отображаются на существующие исходники сервером; приложения, темы и файлы не копируются. Java обращается к общему ProgressStore по абсолютному служебному пути, чтобы новый адрес не ломал импорт. Данные, прогресс и навигация курсов независимы.

Кабинет выбирает каталог серверным параметром `course`; имена курсов проверяются по точному списку. Отдельных аккаунтов, баз данных и сервисов не добавляется. Сессия преподавателя общая, как и раньше; фильтр каталога разделяет интерфейс, а не права доступа.

Старые входы, пути файлов и полный каталог остаются для совместимости. Корень репозитория не публикуется статически: запускать нужно существующий Node-сервер. Обновление GitHub не заменяет обновление процесса или контейнера на VPS.
