# ADR 0002 Доступ преподавателя и общие источники содержания

## Решение

Сохранить клиентские слои курса и локальный прогресс. Добавить HTTP-сервер на встроенных модулях Node.js, который раздаёт сайт, проверяет код преподавателя и выдаёт закрытые материалы. Зависимости времени выполнения не добавляются.

Презентации, сценарии и основные примеры сайта собираются из `lessons/content/lesson-XX.json`. Поле `web` содержит подробное объяснение для ученика, `slides` — этапы занятия, `exercises` — общие вопросы. `site/src/data/course.js` генерируется командой `npm run sync:site`; ручное редактирование запрещено.

## Причины

Статический Nginx не проверял доступ к `/teacher/` и `/lessons/output/`. Форма с проверкой слова в JavaScript не закрывает прямые ссылки. Небольшой сервер решает эту задачу без базы данных и учётных записей детей.

Ранее существовали отдельные источники пособия и сайта. Общий источник и проверка актуальности генерации предотвращают незаметное расхождение опубликованных версий.

## Контракт доступа

`TEACHER_CODES` задаёт список кодов через запятую. По запросу владельца значение по умолчанию — `lesson`; пользовательская настройка заменяет его. Код проверяется на сервере сравнением SHA-256 фиксированной длины. Случайная сессия хранится только на сервере, cookie имеет HttpOnly, SameSite=Strict, Path=/ и срок восемь часов. Выход отзывает сессию. Перезапуск сервера завершает все сессии.

POST требует JSON и совпадения Origin. По умолчанию Origin вычисляется из адреса HTTP-запроса; за HTTPS-прокси задаются `PUBLIC_ORIGIN` и `COOKIE_SECURE=true`. Произвольный X-Forwarded-For не используется. Ограничение входа действует на сетевой адрес подключения: десять попыток за пятнадцать минут. При общем прокси этот предел общий для его пользователей.

Защита распространяется на каталог и файлы. Сервер выдаёт только явно перечисленные финальные DOCX/PPTX. Старые кандидаты остаются в репозитории как история, но недоступны для скачивания через сервер.

## Последствия

Нельзя запускать весь проект через `python -m http.server` или прежний статический Nginx: это обойдёт защиту материалов. Для разработки используется `npm start`, для размещения — новый Dockerfile. Пароли/коды не сохраняются в браузере. В многопроцессной конфигурации потребуется общее хранилище сессий; текущая версия рассчитана на один процесс.

`lesson` является общим словом доступа, а не индивидуальной идентификацией. Личные данные и административные действия этим механизмом не защищаются. Прогресс и ответы учащихся по-прежнему остаются в браузере.

ADR 0001 продолжает действовать в части локального прогресса, но положение о полном отсутствии сервера заменено этим решением.
