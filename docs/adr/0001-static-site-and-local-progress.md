# ADR 0001: Статический сайт и локальный прогресс

## Решение

Первый релиз использует статические файлы и `localStorage` через `ProgressStore`.

## Причины

Задания не требуют аккаунта, совместной работы или серверной проверки Python. Отсутствие сервера исключает сбор персональных данных ребёнка и уменьшает число отказов на уроке.

## Последствия

Прогресс сохраняется только на конкретном устройстве и в конкретном браузере. Если позднее появятся аккаунты, потребуется отдельное согласование по данным детей и новая миграция хранилища.
