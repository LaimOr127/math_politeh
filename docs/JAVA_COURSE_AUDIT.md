# Проверка курса Орбита Java

Дата проверки 12 ноября 2026 года. Курс предназначен для 10–11 классов и сохраняет самостоятельный курс Python.

## Поставка

| Состав | Количество |
|---|---:|
| Занятия по 90 минут | 10 |
| Вопросы самопроверки | 30 |
| Презентации PPTX | 10 по 15 слайдов |
| Сценарии преподавателя DOCX | 10 |
| Общее научно-методическое пособие | 130 страниц |
| Рисунки в общем пособии | 11 |
| Таблицы | 15 |
| Связанные записи содержания | 20 |
| Основные и дополнительные Java примеры | 12 |

Выходные файлы находятся в java-course/output. ZIP включает 21 Office файл, Java исходники проекта и примеры; контрольные суммы находятся в java-course/MATERIALS_MANIFEST.json. Последовательность занятий и инструкции описаны в java-course/README.md. У каждого занятия первые 7 слайдов занимают 45 минут, остальные — ещё 45. Текст преподавателя находится и в заметках PPTX, и в отдельном DOCX; общее пособие включает все 150 этапов в приложении А.

Пособие содержит научное изложение, установку среды, все темы и исполняемые примеры, практику с разбором, вопросы с ответами, методику оценивания, полные сценарии и исходники итогового проекта. Применены A4, поля 30/15/20/20 мм, Times New Roman 14 пт, интервал 1,5, отступ 1,25 см, подписи рисунков/таблиц, нумерация и список источников по применимым положениям ГОСТ 7.32–2017 и ГОСТ Р 7.0.100–2018. Код и таблицы имеют отдельный читаемый кегль. Реквизиты учреждения и автора не выдумывались; вузовский нормоконтроль не заявляется.

## Содержание и ЕГЭ

Содержание сверено с опубликованной спецификацией ФИПИ 2027 по информатике, полученной из официального архива 12.11.2026. Раздел 9 перечисляет Java среди языков, раздел 11 и план задания 23 — оптимальный путь и число путей в DAG. На странице ФИПИ материалы обозначены как проекты; перед экзаменом требуется проверить итоговую редакцию и установленную в школе среду.

Курс тренирует выбранные темы логики, обработки чисел/строк/последовательностей и графов; полного охвата ЕГЭ не заявляет. Задачи авторские. График сложности рассчитан по формулам n и n(n−1)/2, обе оси логарифмические; это не замер времени. Педагогический эксперимент и показатели прироста знаний не выдумываются.

Самостоятельность поддерживают прогноз до запуска, изменение одного условия, поиск минимального контрпримера, обмен ролями в паре и устная защита. Автоматическая проверка числа не оценивает качество объяснения и не доказывает самостоятельность. Защита содержит конкретные эталонные объяснения, а не повтор цели урока.

## Проверки

- npm.cmd run check: 26 тестов, все прошли. Сохранены проверки исходного Python курса.
- JDK Microsoft 21.0.13.0.2: все 12 Java примеров скомпилированы с --release 21; stdout сверяется с общим источником. Проверены ошибочный ввод, недопустимый/отсутствующий файл, границы веса и отрицательные HTTP сценарии.
- Итоговый RoutePlanner сопоставлен с полным перебором на 100 DAG с фиксированным Random(42). Проверены два оптимума, закрытое ребро, недостижимость, старт равный цели и нарушение модели графа.
- Браузер: 212 утверждений, включая 30 неверных и верных ответов, повторную проверку, 10 уникальных завершений, перезагрузку, сброс и экспорт журнала. Первый урок полностью пройден клавиатурой, включая ошибку, исправление, повтор и переход дальше.
- Все 11 маршрутов Java проверены при ширинах 320, 360, 768 и 1440: без горизонтального переполнения, изображения загрузились, ошибок JavaScript не обнаружено. Схемы дополнительно открываются в полном разрешении.
- Кабинет преподавателя проверен в обеих темах при четырёх ширинах. С реального локального сервера получены успешные HEAD для всех 40 файлов двух курсов; private/no-store и attachment присутствуют. Выход отзывает доступ ко всем 22 файлам Java.
- Уведомление об отказе localStorage проверено в браузере с запрещённым хранилищем; состояние остаётся в памяти, сообщение имеет role=status. Прогресс Python и Java разделён.
- Каждый PPTX прошёл проверку пакета, геометрии, количества слайдов и повторный импорт Artifact Tool; все 150 слайдов отрисованы. Все 11 DOCX отрисованы Documents renderer через LibreOffice. Проверены контактные листы и увеличенные изображения проблемных мест; исправлены потерянный символ схемы, положение номеров содержания, переносы листингов и растянутый многострочный вывод.
- Содержание общего пособия повторно проверено по финальному PDF: 20 ссылок и реальные страницы 130-страничного издания. XML проверяет формат страницы, доступность текста и совпадение материалов с источниками.
- Для Java примеров и входных TXT закреплён LF в .gitattributes, чтобы строгая проверка генерации работала после checkout в Windows.

Протоколы и изображения QA находятся локально в .build/java-review и .build/java-slides и не включаются в Git. Встроенный preview дважды завершился ошибкой snapshot с текстом Preview automation snapshot timed out after 15000ms; визуальная проверка продолжена во внешней среде Chromium/Playwright. В зависимости сайта браузерные инструменты не добавлены.

## Безопасность и ревью

Применены Ponytail, Frontend Design, Documents, Presentations, PDF, Security Best Practices для JavaScript/Python, Web Design Guidelines и проверка по Ponytail Review/Review Agent. Ревью проведено с чтением связанных вызовов, API, тестов, публичных данных и доступа к файлам; дополнительные агенты не запускались. Context7 не подключён по доступным инструментам, поэтому использована официальная документация Java, Microsoft и ФИПИ.

Новых подтверждённых блокирующих дефектов после исправлений не осталось. Разделены ключи прогресса, исключены полные сценарии из публичного JS модуля, сохранены CSP и ограничения сервера. В новом интерфейсе нет исполнения пользовательского кода, вставки пользовательских строк через innerHTML или отправки программ/объяснений во внешние сервисы. Публичные ответы самопроверки не считаются секретом.

Материалы Java включены в ту же серверную сессию и точный список файлов, что и Python. Общий код lesson оставлен по указанию владельца: это общий доступ к материалам, не личная идентификация и не защита персональных данных. Итоговый Java HttpServer слушает только 127.0.0.1 и рассчитан на локальную учебную работу.

## Границы проверки

Презентации и документы проверены отрисовкой и структурно; воспроизведение анимаций в Microsoft PowerPoint и пагинация в Microsoft Word отдельно не проверялись. Проверки не являются нагрузочным испытанием, внешним тестом проникновения или педагогическим исследованием. Docker сборка не запускалась: на текущей машине остаётся ранее установленное ограничение аппаратной виртуализации. Node запуск проверен на 26.13.1.

Изменения подготовлены для локального запуска и Git. Развёртывание на 83.217.202.54 не выполнялось: доступ к размещению не предоставлен. Git push сам по себе не обновляет прежний статический сервер; существующее ограничение публичной версии описано в docs/SITE_AUDIT.md и security_best_practices_report.md.

## Независимые адреса курсов: проверка 12 ноября 2026 года

Под одним origin подготовлены `/python/` и `/java/`, кабинеты — `/python/teacher/` и `/java/teacher/`. Между курсами нет навигационных ссылок; каждый кабинет запрашивает свой каталог. Старые адреса и полный каталог сохранены. Сессия преподавателя остаётся общей и не является разделением прав между курсами.

После изменения маршрутов `npm run check` прошёл 28 тестов. Chromium/Playwright выполнил 241 проверку без ошибок браузера: 10 занятий Java, неверный и повторный ответ, перезагрузка, клавиатура, сброс, оба кабинета, старый кабинет, ширины 320/360/768/1440 и обе темы кабинетов. При прогоне обнаружена и исправлена попытка прочитать каталог из ответа входа в старом кабинете. Снимки обоих новых кабинетов просмотрены. Защита файлов и проверка параметра course покрыты серверными тестами.

Проверены связанные вызовы маршрутов, API каталога и авторизации, импорты модулей, ссылки на материалы и границы публикации файлов. Подтверждённых блокирующих дефектов в текущем изменении не осталось. Новых зависимостей не добавлено. VPS остаётся не обновлённым: SSH-доступ пока не предоставлен. Инструкция размещения и внешней приёмки находится в docs/DEPLOYMENT.md.
