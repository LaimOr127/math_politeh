# Проверка сайта и согласование с Генезис-X

Дата: 12 ноября 2026 года. Проверены исходники, локальный Node-сервер и публичный экземпляр, указанный владельцем. Применены Ponytail, Frontend Design, Security Best Practices, Web Design Guidelines; итоговый diff проверен по Ponytail Review и Review Agent без изменения файлов во время ревью.

## Принятая визуальная система

Образец: https://genesis-x-demo-five.vercel.app/directions/digital-school. В браузере проверены действующие шрифты, цвета, композиция и связь companion с «Спросить Искру» в коде основного сайта.

| Роль | Цвет |
| --- | --- |
| Космический фон | #171329 |
| Светлый фон | #F3F0FA |
| Первый экран | #EEE7F5 |
| Поле иллюстрации | #DDD2E8 |

| Текст первого экрана | #30253E |

Onest отвечает за текст и заголовки; Unbounded — за название платформы. Текст выровнен влево. На широком экране герой состоит из текста и иллюстрации, на узком — из последовательных блоков:

```text
[ Генезис-X                   меню и тема ]
[ Цифровая школа                          ]
[ Python, цель, начало урока | Искра       ]
[ Прогресс и восемь деталей                ]
[ Последовательная карта восьми миссий     ]
```

Главный акцент — исходная Искра с бумажной фактурой. Убраны выделение отдельной части заголовка, лишние прописные подписи и бесконечная анимация. Короткое появление робота отключается правилом prefers-reduced-motion. Пытик остаётся героем учебных историй; знакомство объясняет отличие от Искры.

## Исправленные дефекты

- JSON null при входе: 500 заменён на 400 с проверкой структуры входа.
- Кириллический код на границе сетевых фрагментов: байты собираются с лимитом 2048 и декодируются один раз.
- Ссылка «К содержимому»: сохраняет маршрут урока и переводит фокус в main.
- Смена маршрута при открытом знакомстве: фокус остаётся в диалоге; фон inert.
- Длинный код в мобильном уроке: колонка minmax(0, 1fr) не растягивает страницу.
- Минимальная ширина body больше области страницы с полосой прокрутки: горизонтальное переполнение при 320 px устранено.

## Проверки локальной версии

- `npm.cmd run check`: 20 из 20 тестов, включая актуальность общих уроков и всех опубликованных Office-материалов.
- До серверного исправления два новых регрессионных теста падали: null → 500, фрагментированный кириллический код → 401; после исправления проходят.
- Реальный браузер: все 8 уроков и 24 задания, неправильный и правильный ответы, повторная проверка без второй награды, одна деталь за урок. После сброса весь курс повторно пройден с нуля на 320 px: 122 успешных утверждения. На 360 px — 121 утверждение.
- Частичный прогресс после загрузки документа восстанавливает задание 2; тема сохраняется. Закрытый следующий урок недоступен до завершения предыдущего.
- Сброс после восьми деталей: 0 деталей, тёмная тема сохранена, фокус в main. Подтверждение принято через браузерный инструмент диалогов.
- Клавиатура: Tab/Shift+Tab в знакомстве, Escape, Space для радиокнопки, Tab и Enter для проверки неправильного ответа; фокус переходит к подсказке. «К содержимому» сохраняет #lesson/hello.
- Ширина 320 и 360 px: весь курс без горизонтального переполнения. 768 и 1440 px: по 11 маршрутов в обеих темах без переполнения (главная, 8 уроков, тест, вход к материалам).
- Визуально просмотрены первый экран на 1280 px в светлой теме, знакомство и первый экран на 360 px в тёмной теме. Часть последующих снимков Preview завершалась тайм-аутом; проверки DOM/геометрии и сценариев при этом работали. Проверка на физическом телефоне не выполнялась.
- Контраст основных пар текст/фон после завершения переходов в обеих темах: минимум 5,17:1 среди навигации, текста первого экрана, основной кнопки, текста уроков на карте и прогресса. Это выборочная проверка, не сертификация WCAG всего сайта.
- Кабинет преподавателя: неправильный код и фокус поля, вход lesson, 8 уроков и 18 ссылок; каждый файл отвечает 200 на HEAD только после входа. Полная загрузка PPTX: ZIP-сигнатура и длина совпадают. Сессия восстанавливается после загрузки страницы; выход возвращает 401 на сессию и файл. Каталог и форма без переполнения при 320 px.
- Локальные изображения и четыре шрифта загружаются без ошибок; HttpOnly-cookie не видна через document.cookie. В просмотренных снимках консоль не содержала ошибок приложения.

## Размещённый сайт: обновление ещё требуется

На http://83.217.202.54:8080/site/#home по-прежнему показано «Привет! Я Пытик.». `/health` и `/api/teacher/session` возвращают 404, а `/lessons/output/new-learning-guide.docx` — 200 без входа. Это старая статическая поставка, а не проверенный локальный сервер.

Нужно развернуть текущий проект по существующим Dockerfile/compose.yaml либо запустить `npm start` под менеджером процессов. Все пути, включая /lessons/, должны идти через Node; прежний статический location для материалов нужно убрать. После настройки HTTPS указать PUBLIC_ORIGIN и COOKIE_SECURE=true. Повторная приёмка: /health → 200, файл без входа → 401, вход/выход, 18 скачиваний, Искра и обе темы. Не считать push развёртыванием.

Доступа SSH или настроенного канала CI/CD в текущей сессии нет. Изменений на VPS эта проверка не вносила. Риски размещения отдельно описаны в `../security_best_practices_report.md`.

## Результат ревью изменений

No findings. После исправлений новых подтверждённых дефектов в diff не найдено. Проверены обработка HTTP-тела и её тесты, связанные обработчики навигации/фокуса, оба потребителя темы, новые ресурсы, CSS и документация. Расчётная конфигурация — один Node-процесс, как в ADR 0002. Эта проверка не является независимым ревью другим агентом.

Ограничения: неизвестная конфигурация VPS/прокси, отсутствие публикации, отсутствие запуска Docker на этом ПК, физического телефона и полной сертификации доступности. Проверены доступные браузерные сценарии и тесты Node; исходные программы и 18 Office-файлов прошли существующие проверки актуальности, их содержимое в этой задаче не переписывалось.
