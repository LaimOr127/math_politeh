# Состояние переработки

Комплект ещё требует проверки перед проведением занятий. Новые презентации `lesson-XX-visual-candidate.pptx` и сценарии `lesson-XX-teacher-script-v2.docx` находятся рядом с прежними шаблонными файлами; не путайте версии.

## Выполнено

- В `lessons/content/` написаны исходники всех восьми уроков: по 18 слайдов и 45 минут, с речью, вопросами, ответами и тремя упражнениями. Они требуют педагогической проверки перед выпуском.
- Переработаны правила миссий и прогресса сайта: вторая версия хранилища поддерживает несколько упражнений, восстанавливает первую незавершённую миссию и переходит в режим текущей вкладки при недоступном хранилище. Версия 1 мигрируется.
- Интерфейс показывает собираемого робота и сертификат после последней миссии. Данные текущих миссий пока прежние, поэтому в них ещё по одному упражнению.
- Из общих данных собраны восемь новых презентаций и сценариев; старые опубликованные файлы не заменялись. Слайды и страницы отрендерены для проверки, структура PPTX проверена; раскрытие ответа на одном слайде проверено в PowerPoint.

## Осталось

1. Провести педагогическую проверку всех уроков и сверить их с материалами сайта.
2. Соединить все восемь миссий сайта с согласованными источниками уроков и проверить миграцию данных при смене идентификаторов упражнений.
3. Снять реальные кадры скачивания, установки и настройки Python и VS Code, а также запуска каждого примера. Один снимок выбора папки находится в `site/assets/screenshots/`; он не заменяет пошаговое пособие.
4. Подготовить `lessons/setup-guide.json` и иллюстрации, проверить остальные анимации в PowerPoint и визуально просмотреть все слайды в целевых приложениях.
5. Обновить README, архитектуру, API и документацию по сборке; настроить hook и проверить сайт в браузере с клавиатурой и на узком экране.

Тесты `npm run check` проверяют доменную логику и хранилище. Они не подтверждают правильность уроков, работу интерфейса в браузере или готовность документов.
