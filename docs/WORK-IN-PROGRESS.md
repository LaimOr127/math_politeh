# Состояние учебного комплекта

Текущая поставка содержит восемь презентаций, восемь сценариев, пособие ученика и сводное научно-методическое пособие. Источники находятся в lessons/content. Старые кандидаты сохранены в репозитории, но не раздаются сервером.

Доработки и границы проверки перечислены в REVIEW.md. Остаются педагогическая апробация на реальной группе и проверка анимаций в целевой версии Microsoft PowerPoint. Полного иллюстрированного руководства установки для всех ОС пока нет: пособия содержат текстовые инструкции.

Внешний сайт обновляется отдельным развёртыванием после получения доступа к размещению.
