# Состояние учебных комплектов

Актуализировано 24 ноября 2026 года.

Опубликованы два самостоятельных курса под одним адресом: Python — /python/, Java — /java/. Кабинеты преподавателя находятся в /python/teacher/ и /java/teacher/. Вход проверяется сервером; общий код не является персональной учётной записью.

Python содержит восемь занятий, восемь презентаций по 18 слайдов, восемь сценариев, пособие ученика и общее научно-методическое пособие. Java содержит десять занятий, десять презентаций по 15 слайдов, десять сценариев и общее научно-методическое пособие. Источники: lessons/content и java-course/content/course.json. Старые кандидаты остаются в репозитории, но не раздаются сервером.

При повторной проверке исправлено неверное описание связи графов с заданием 23 ЕГЭ в Java. Уточнение внесено в источник, сайт, три презентации и научное пособие. Все 18 презентаций и 21 опубликованный Word-файл отрисованы; сводные пособия содержат 131 и 130 страниц. Методика и границы проверки описаны в [FULL_REVIEW_2026-11-24.md](FULL_REVIEW_2026-11-24.md).

Остаются педагогическая апробация на реальной группе, проверка анимаций в целевой версии Microsoft PowerPoint и нормоконтроль титульных реквизитов конкретного учреждения. Инструкции установки текстовые; пошаговых снимков каждого установщика для всех ОС нет. Публичный адрес пока использует HTTP; переход на HTTPS требует отдельной настройки размещения.

Обычный Git push не обновляет VPS. Порядок и проверенные выпуски описаны в [DEPLOYMENT.md](DEPLOYMENT.md).
