## Context7

Плагин найден в каталоге и предложен пользователю для подключения. Повторная проверка каталога: installed=false. Действующее подключение и вызов инструмента не подтверждены. Завершение установки и вход в Context7 выполняются через карточку подключения. Пароли и API-ключи в переписку не нужны.

Второй ручной MCP-сервер не добавлен, чтобы не дублировать тот же источник после подключения плагина. Текущий config.toml сохранён без изменений. До подключения использовать официальную документацию библиотек; после подключения — Context7 для соответствующей версии API. Не отправлять сервису секреты и частные исходники.

## Graphify на Windows

Инструмент и его зависимости находятся в отдельном venv:

- C:/Users/Admin/.local/share/codex-tools/graphify
- C:/Users/Admin/.local/bin/graphify.cmd — запуск из нового терминала; каталог добавлен в пользовательский PATH.

В зависимости сайта и системный Python эти пакеты не добавлены. Постоянный процесс, перехваты команд и git hooks не устанавливались. Параметры модели и провайдера Codex не менялись.

Построить или актуализировать локальный граф из корня проекта:

~~~powershell
$env:PYTHONUTF8 = '1'
$env:GRAPHIFY_BACKEND = 'none'
graphify.cmd extract . --code-only --exclude '.env' --exclude '*.zip' --exclude 'lessons/output/**' --exclude 'node_modules/**' --exclude '.build/**'
graphify.cmd query 'teacher session createApp'
~~~

В уже открытом терминале PATH может быть старым. Тогда использовать полный путь к graphify.exe из venv. Режим --code-only извлекает связи из кода без семантической обработки документов и вызовов моделей. Секреты и генерируемые материалы исключены. Локальные результаты graphify-out/ исключены из Git.

Проверенный результат: 36 файлов кода, 196 узлов, 319 связей, 13 сообществ. Выполнен запрос по teacher/session/createApp. Граф не заменяет чтение кода: пять файлов тестов не дали самостоятельных символов, но их логика остаётся существенной. Граф текущего запуска не содержит смыслового разбора Word, PPTX, JSON-уроков и документации.

## Постоянные правила

Общие предпочтения сохранены в C:/Users/Admin/.codex/AGENTS.md, проектные дополнения — в корневом AGENTS.md. Навыки применять по задаче, не загружать все одновременно. Пользовательские требования и архитектурные правила проекта имеют приоритет над рекомендациями навыков. ponytail не отменяет JSDoc, тесты, безопасность, доступность или полноту работы.

При изменении интерфейса сохраняются космическая тема, аудитория 10–12 лет, обе цветовые схемы, мобильная компоновка, клавиатурная навигация и reduced motion. Оптимизация должна опираться на измерения, а архитектурные изменения — на реальные границы и данные проекта.
