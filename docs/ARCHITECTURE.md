# Архитектура игрового сайта

## Границы

Сайт статический. Он не имеет HTTP API, сервера, учётных записей и внешнего хранилища. Единственный сохраняемый объект - локальный прогресс браузера.

Для запуска в Docker один контейнер с Nginx раздаёт статические файлы: `/site/` — интерфейс, `/lessons/output/` — имеющиеся учебные материалы, `/` перенаправляет на `/site/`. Файлы копируются в образ при сборке, поэтому после изменений нужна пересборка. Compose публикует порт 8080 по умолчанию; `PORT` позволяет его изменить. Контейнер не хранит пользовательский прогресс и не запускает Python-код учеников.

## Слои

```text
data/missions.js -> domain/Mission.js -> ui/app.js
                         |
                         v
                storage/ProgressStore.js
```

- `data` описывает уроки, код и задания декларативно.
- `domain` проверяет ответы и определяет доступность следующей миссии.
- `storage` валидирует и сохраняет снимок прогресса.
- `ui` отображает данные и передаёт действие пользователя доменному слою.

Зависимости направлены только вниз по схеме. Модуль интерфейса не знает ключа `localStorage`, а хранилище не импортирует DOM.

## Инкапсуляция

`ProgressStore` хранит приватный ключ, версию схемы и адаптер хранилища. Внешний код получает копию снимка через `load()` и меняет его только методами `completeMission()` или `reset()`. Это исключает разрозненные записи в `localStorage` и даёт одно место для миграции формата.

## Обновление контента

Миссия добавляется в `data/missions.js`, затем получает тест в `site/tests/` и запись в `docs/CONTENT_MODEL.md`. Не добавляйте для новой миссии отдельный обработчик или отдельную HTML-страницу.

## Навигация и материалы

Текущий интерфейс использует данные `site/src/data/course.js` и маршруты `#home`, `#lesson/{id}`, `#test/{id}`, `#materials`. Пытик знакомит с картой, уроками и проверкой; знакомство можно пропустить или открыть через «Помощь». После текста урока доступны три вопроса. Раздел материалов содержит краткое пособие и обозначенные черновики. Старые презентации и сценарии ещё не отвечают полному ТЗ.
