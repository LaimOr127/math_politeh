# Контракты приложения

## HTTP

API возвращает JSON с Cache-Control no-store. Учебные файлы имеют private no-store. Клиент использует same-origin fetch; HttpOnly cookie JavaScript не читает.

| Метод и путь | Действие | Основные ответы |
| --- | --- | --- |
| GET /health | Проверка процесса | 200 |
| POST /api/teacher/login | JSON с полем code | 200, 400, 401, 403, 413, 429 |
| GET /api/teacher/session | Проверка сессии | 200 или 401 |
| GET /api/teacher/materials | Каталог lessons, guides и javaCourse | 200 или 401 |
| POST /api/teacher/logout | Отзыв сессии | 200, 403 |
| GET /lessons/output/имя | Разрешённый DOCX/PPTX | 200, 401, 404 |

Вход принимает JSON-объект с текстовым `code`. Некорректный JSON, `null`, массивы, скаляры и нетекстовый код возвращают 400; неверный текстовый код — 401. Тело ограничено 2048 байтами (413 при превышении); UTF-8 декодируется после получения всех частей запроса.

POST требует Content-Type application/json и Origin текущего сайта. За HTTPS-прокси задаётся PUBLIC_ORIGIN. TEACHER_CODES заменяет код по умолчанию lesson; несколько кодов разделяются запятыми.

Cookie python_lab_teacher имеет HttpOnly, SameSite=Strict, Path=/ и срок восемь часов. COOKIE_SECURE=true добавляет Secure. Перезапуск завершает сессии. Лимит — десять попыток за пятнадцать минут на адрес подключения; 429 содержит Retry-After. Старые файлы не выдаются даже после входа.

`createApp({codes, now, sessionMs, maxAttempts, attemptWindowMs, secureCookies, publicOrigin})` возвращает незапущенный http.Server. Параметры времени и лимитов подменяются в тестах. `server/index.js` открывает порт с PORT и HOST.

## Миссии

`new Mission(definition)` валидирует упражнения. `validate(answer, exerciseId)` возвращает `{correct, message}` без побочных эффектов. `isUnlocked(completedIds, previous)` определяет доступность. `nextMission(missions, completedIds)` выбирает первый доступный незавершённый урок, а после курса — последний.

## Прогресс

`new ProgressStore(storage, missions, key = 'python-lab-progress')` получает Storage или функцию адаптера. `load()` возвращает независимую копию `{version:2, completedIds, stars, solved}`. `completeExercise(missionId, exerciseId)` сохраняет ответ и выдаёт деталь после всех упражнений; повтор не увеличивает награду. `reset()` очищает учебный прогресс. `persistent` сообщает о доступности сохранения. При ошибке данные остаются во вкладке.

Версия 1 и прежние завершённые уроки с упражнением main мигрируются. Повреждённые и нарушающие последовательность данные отклоняются.

## Отображение

`PreferencesStore(storage).load()` возвращает `{theme, introSeen}`. `setTheme(theme)` принимает light, dark или system. `dismissIntro()` отмечает просмотр знакомства. Ошибки хранения не мешают работе. `applyTheme()` меняет data-theme, подписи переключателей и meta theme-color. До выбора учитывается системная тема.

Маршруты: #home, #lesson/id, #test/id, #materials. После перезагрузки тест открывается на первом нерешённом вопросе. Знакомство удерживает фокус даже при смене маршрута, фон получает inert, Escape закрывает окно. Ссылка «К содержимому» переводит фокус на main без изменения маршрута урока; после сброса фокус возвращается в main.

## Сборка печатных материалов

`build_documents.py [--scientific-only]` читает восемь JSON-уроков и собирает Word-файлы. Флаг ограничивает изменение общим иллюстрированным пособием. `build_illustrations.build_course_figures(lessons)` сохраняет 11 поясняющих PNG из канонических данных в `lessons/illustrations/`; зависимости используются только при авторской сборке.

`update_scientific_contents.py <rendered.pdf> [--docx путь] [--entries путь] [--check]` читает PDF отрисовки и получает реальные страницы 21 пункта содержания. По умолчанию обновляет существующий DOCX через временный ZIP, сохраняя остальные части пакета, и добавляет внутренние ссылки. `--check` сверяет финальную пагинацию без изменения документа. Нужен pdfplumber из Codex runtime.

`verify_materials.py` проверяет все 18 опубликованных Office-файлов по урокам и структуру общего документа: поля, шрифты без подмены темой, интервалы, изображения, подписи, приложения и готовое содержание. `package_materials.py` выполняет проверку и упаковывает ровно эти 18 файлов. Черновики и промежуточные PDF/PNG в поставку не включаются.

## Курс Java

`GET /site/java/` открывает самостоятельный тёмный интерфейс. Маршруты: `#home`, `#setup`, `#java-01` … `#java-10`. Материалы доступны для чтения сразу; сохранение результатов открывается последовательно. Ключ прогресса `java-orbit-progress` отделён от Python. Объяснения сохраняются в памяти вкладки и выгружаются кнопкой «Скачать журнал»; перед закрытием несохранённого журнала браузер предупреждает.

`checkAnswer(task, value)` сравнивает числовую строку после удаления крайних пробелов, не исполняя её. `shortestPath(edges, start, end)` принимает направленные рёбра `[from,to,weight]` с конечным неотрицательным весом и возвращает `{distance,path}`; для недостижимой цели — Infinity и пустой путь. Это чистая функция Дейкстры для небольшой учебной карты, не обработчик публичного произвольного графа.

`/api/teacher/materials` сохраняет прежние `lessons` и `guides`, добавляя `javaCourse: {title,lessons,guides}`. Каждый урок Java содержит `id,title,duration,presentation,script`. Доступ к `/java-course/output/…` проверяет ту же сессию и точный список: 10 PPTX, 10 DOCX сценариев, общее DOCX пособие и ZIP. Заголовки — private/no-store и attachment. Исходники java-course, кандидаты и служебные файлы через сервер не раздаются.

`npm run sync:java` генерирует ученический модуль и примеры из одного JSON. Полные teacher/slides данные остаются за пределами публичного модуля. Автоматические ответы на самопроверку по природе клиентские и не считаются секретом. Office собирается отдельными скриптами в java-course/scripts; readme курса описывает отрисовку, содержание и упаковку.

## Адреса для внедрения на основном сайте

| Ученический курс | Кабинет преподавателя | Каталог после входа |
|---|---|---|
| `/python/` | `/python/teacher/` | `/api/teacher/materials?course=python` |
| `/java/` | `/java/teacher/` | `/api/teacher/materials?course=java` |

Все пути используют один origin. Адрес без завершающего слеша перенаправляется кодом 308, query сохраняется. Сервер не перенаправляет новый вход на старый `/site/`: адрес курса остаётся видимым при работе и перезагрузке. `/python/java/` не является входом в Java и возвращает 404.

Каталог с `course` возвращает `{course,title,lessons,guides}` только выбранного курса. `course` принимает ровно одно значение `python` или `java`; пустое, неизвестное или повторённое значение возвращает 400 после проверки сессии. Без сессии — 401. Без параметра сохраняется прежний полный каталог. Пути защищённых загрузок и требования к Origin/cookie не меняются. Старые ссылки и прогресс действуют.
