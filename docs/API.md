# Контракты сайта

Внешнего HTTP API нет. Это статическое приложение; маршруты после `#` обрабатывает браузер.

## Миссии

`new Mission(definition)` проверяет идентификаторы упражнений, варианты, ответы и обратную связь. `validate(answer, exerciseId)` возвращает `{correct, message}`. `isUnlocked(completedIds, previous)` проверяет прохождение предыдущего урока. `nextMission(missions, completedIds)` возвращает первый доступный незавершённый урок или последний, если курс пройден.

## Прогресс

`new ProgressStore(storage, missions)` принимает Storage или функцию его получения и список миссий с упражнениями. `load()` возвращает независимую копию `{version: 2, completedIds, stars, solved}`. `completeExercise(missionId, exerciseId)` записывает решённое упражнение; деталь начисляется после всех упражнений урока. `reset()` сбрасывает прогресс; `persistent` показывает, доступно ли сохранение. При ошибках хранилища данные остаются в памяти текущей вкладки, интерфейс предупреждает об этом.

Прогресс версии 1 и завершённые миссии версии 2 с прежним единственным заданием `main` преобразуются в завершённые уроки с новыми заданиями. Остальные повреждённые данные отклоняются.
