На основном сайте разместите отдельные обычные ссылки в нужных разделах. Курсы не предлагают переход друг к другу. При замене IP на домен достаточно заменить origin в ссылках; пути сохраняются. Прогресс курсов разделён, сброс одного не очищает другой. Старые `/site/`, `/site/java/` и `/teacher/` продолжают работать.

Общие сервер, ресурсы и сессия преподавателя являются инфраструктурой. Отдельных поддоменов и отдельных процессов для каждого курса не требуется. Кабинет каждого курса показывает свои презентации, сценарии и пособия. Код входа настраивается через TEACHER_CODES, по умолчанию lesson.

## Обновление существующего VPS

Нужны подтверждённый SSH-пользователь, путь установленного проекта и способ запуска. Не подставляйте предположительный каталог и не останавливайте неизвестный процесс на 8080. Сначала определите текущий процесс/контейнер и сохраните его конфигурацию. Реальные коды и .env не должны попадать в Git.

Для Docker Compose установки, где подтверждённая папка проекта уже является Git checkout:

```sh
git status --short
git fetch origin
git pull --ff-only origin main
docker compose up --build -d
docker compose ps
```

Если в серверной копии есть локальные изменения или git pull обнаружил расхождение, сначала выясните их назначение. Не выполнять reset --hard и не переписывать историю автоматически. Перед обновлением запишите текущий commit и сохраните используемый образ/конфигурацию для отката.

При установке без Docker используется Node.js 22+ и `node server/index.js` из корня проекта с прежним окружением; перезапускается именно существующая служба через её менеджер процессов. Имя службы определяется на сервере, а не угадывается.

Для прямого HTTP на 8080 PUBLIC_ORIGIN при необходимости равен `http://83.217.202.54:8080`, COOKIE_SECURE=false. Для HTTPS задайте реальный внешний origin и COOKIE_SECURE=true. При обратном прокси передавайте серверу пути без удаления `/python/` или `/java/`, а также `/site/` (общие ресурсы), `/teacher/` (общий скрипт), `/api/teacher/`, `/lessons/output/` и `/java-course/output/` (проверка доступа к материалам). Проще проксировать весь выделенный origin на один Node-процесс.

2. Оба ученических адреса и их уроки работают после перезагрузки; изображения, шрифты и модули загружаются.
