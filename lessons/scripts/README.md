# Сборка учебных материалов

Источники — `lessons/content/lesson-XX.json`. Сайт, вопросы, основные примеры и печатные материалы используют эти данные.

## Сайт

```sh
npm run sync:site
npm run check
```

Генератор не требует внешних пакетов. Изменения course.js проверяются при каждом `check`.

## Презентации

Используется Node.js и `@oai/artifact-tool` из выбранного Codex runtime. Пакеты не нужно устанавливать в проект. Передаются RUNTIME_PYTHON, RUNTIME_NODE_MODULES и PRESENTATIONS_SKILL_DIR.

```sh
node lessons/scripts/create_presentations.mjs
```

Каждый урок имеет 18 слайдов и длительность 45 минут. Текст и код редактируемые, речь преподавателя находится в заметках. `animate_pptx.py` добавляет стандартное раскрытие нижнего ответа по щелчку. В PDF ответы видны сразу.

Сборщик проверяет PPTX и сохраняет финальный файл `lesson-XX-presentation.pptx`. `LESSON_ID=01` ограничивает сборку одним уроком. `RENDER_SLIDES=0` отключает внутренний PNG-экспорт, если последующая проверка выполняется через LibreOffice. Перед выпуском отрисуйте все финальные слайды и проверьте переносы, читаемость и ответы. Временные файлы и отчёты находятся в `.build/`.

## Word

Используйте Python из Codex runtime с python-docx и lxml:

```sh
python lessons/scripts/build_documents.py
```

Создаются восемь `lesson-XX-teacher-script.docx`, `new-learning-guide.docx` и `scientific-methodical-guide.docx`. Сценарии включают все этапы, речь преподавателя, вопросы и решения. Сводное пособие содержит методику, архитектуру, восемь тем, общие программы, ключи вопросов и планирование.

Перед авторством файлов в среде Codex выполните маркер операции из соответствующего навыка. После сборки каждый DOCX проверяется `render_docx.py` навыка Documents. На Windows нужны установленные LibreOffice и Poppler из Codex runtime в PATH. PNG и PDF проверки не являются отдельными публикациями.

`python lessons/scripts/verify_materials.py` сверяет содержимое всех опубликованных файлов с источниками. `python lessons/scripts/package_materials.py` после проверки собирает 18 файлов в `lessons/python-course-materials.zip`.

Ввод пользователя и stdout приводятся отдельно, без выдуманного эха терминала. Не добавляйте ссылки на отсутствующие изображения. Предыдущие `create_teacher_scripts.py`, `create_web_guide.py` и `create_visual_previews.mjs` сохранены для истории; опубликованный выпуск создаётся командами выше.

## Проверка

Проверяйте совпадение основных примеров и вопросов с сайтом, исполнение Python, длительность, наличие 18 слайдов и заметок. Структурная проверка не подтверждает анимацию в конкретной версии PowerPoint; воспроизведение проверяется отдельно в целевом приложении.
