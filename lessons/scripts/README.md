# Сборка учебных файлов

Единственный источник содержания — `lessons/content/lesson-01.json` … `lesson-08.json`.
Скриншоты берутся из `site/assets/screenshots`, схемы — из `site/assets/illustrations`.
Отсутствующая картинка останавливает сборку. Текст настройки находится в `lessons/setup-guide.json`.

## Презентации

Нужны Node.js с установленным `@oai/artifact-tool`, Python с `lxml` и пакет инструментов Presentations из Codex. Пути передаются явно, не зашиты в исходники:

```sh
export RUNTIME_PYTHON=/absolute/path/to/bundled/python3
export PRESENTATIONS_SKILL_DIR=/absolute/path/to/presentations/skill
node lessons/scripts/create_presentations.mjs
```

Для одной презентации задайте `LESSON_ID=01`. `RENDER_SLIDES=0` отключает PNG только для технической пересборки; перед выпуском превью обязательны. Проверенные PPTX копируются в `lessons/output`; сборка разрешает перезаписать свои результаты. Промежуточные файлы и отчёты лежат в `.build/artifacts`.

`animate_pptx.py` добавляет стандартные OOXML-анимации входа к фигуре `reveal-answer`. В показе один щелчок открывает ответ или результат. В режиме редактирования и PDF ответ виден сразу. Скрипт не анимирует произвольный текст и не заменяет показ слайдов.

## Документы

Нужны Python, `python-docx` и `lxml` из выбранной среды:

```sh
"$RUNTIME_PYTHON" lessons/scripts/create_teacher_scripts.py
```

`--scripts-only` создаёт только восемь сценариев. Каждый слайд имеет собственный раздел, интервал времени, речь, действия и ответ. Пособие включает все шаги настройки, теорию и решения.

Для визуальной проверки используйте `render_docx.py` из навыка Documents с выбранным bundled Python. Он сам выбирает LibreOffice и Poppler из того же runtime. Не заменяйте его установленным настольным LibreOffice. PNG/PDF проверки остаются в `.build/artifacts`.

## Контракты функций

- `build(lesson)` в `create_presentations.mjs`: проверяет длительность/число слайдов и изображения; создаёт PPTX, добавляет анимации, запускает проверки пакета и сохраняет превью. Ошибка прекращает сборку.
- `animate(path)`: атомарно заменяет PPTX, сохраняя остальные ZIP-части; добавляет timing для именованных фигур. Без целевых фигур завершает работу с ошибкой.
- `teacher_script(lesson)`: создаёт DOCX, синхронизированный со слайдами и решениями.
- `guide(lessons, setup)`: создаёт общее пособие из тех же данных и фактических изображений.
- `document`, `paragraph`, `code`, `picture`: только оформление документа. `picture` требует существующий файл и записывает альтернативную подпись.

Проверяйте также Python-примеры и суммы минут через общие проверки проекта. Структурная проверка PPTX не подтверждает воспроизведение анимаций в конкретной версии PowerPoint: это отдельная проверка показа.

## Новые визуальные презентации

`create_visual_previews.mjs` собирает все восемь уроков из `lessons/content/` с редактируемыми схемами и заметками. Запуск использует те же переменные `RUNTIME_PYTHON` и `PRESENTATIONS_SKILL_DIR`, что и выше; `LESSON_ID=01` ограничивает сборку одним уроком. Проверенные кандидаты находятся в `.build/review/`; копии для просмотра — `lessons/output/lesson-XX-visual-candidate.pptx`. Сборщик не перезаписывает прежние презентации. Word-сценарии в `lesson-XX-teacher-script-v2.docx` синхронизируются с теми же JSON командой `create_teacher_scripts.py --scripts-only`.

Файлы остаются кандидатами: проверены структура, выборочные слайды и раскрытие ответа на одном слайде в PowerPoint, но не все эффекты на всех устройствах. Требуются реальные снимки скачивания, установки и работы в VS Code; один имеющийся снимок показывает окно выбора папки в macOS. Краткое пособие `new-learning-guide.docx` не заменяет полное пошаговое пособие.
