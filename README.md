# Лаборатория Питона

Учебный комплект по Python для 5-6 класса: пособие, уроки и игровой сайт.

## Быстрый старт сайта

Установите Docker с поддержкой Compose и запустите Docker Desktop или Docker Engine. В терминале из корня проекта выполните:

```bash
docker compose up --build -d
```

Откройте `http://localhost:8080/`: сервер перенаправит на `/site/`. Для остановки выполните `docker compose down`. Чтобы увидеть сообщения сервера, используйте `docker compose logs -f site`. После изменения файлов повторите `docker compose up --build -d`: сайт и находящиеся в `lessons/output/` материалы копируются в образ при сборке.

Если порт 8080 занят, укажите другой при запуске: `PORT=8081 docker compose up --build -d` (в PowerShell: `$env:PORT=8081; docker compose up --build -d`), затем откройте соответствующий порт. Для другого устройства в локальной сети используйте адрес компьютера с Docker, например `http://192.168.1.10:8080/`; доступ зависит от настроек сети и брандмауэра. Контейнер публикует порт на всех сетевых интерфейсах, поэтому сайт может быть доступен другим устройствам сети. Прогресс хранится отдельно в браузере каждого устройства и не переносится вместе с контейнером.

Для локальной разработки без Docker можно выполнить `python3 -m http.server 8000` из корня проекта и открыть `http://localhost:8000/site/`. Открывать HTML-файл напрямую не следует: браузеру нужен HTTP для загрузки JavaScript-модулей.

## Проверка

```bash
npm run check
```

Команда запускает тесты правил миссий и инкапсулированного хранилища прогресса. Перед изменением сайта прочитайте `docs/ARCHITECTURE.md` и `docs/CONTENT_MODEL.md`.

## Состав

- `site/` - игровой сайт «Лаборатория Питона».
- `docs/` - архитектура, контракты, модель учебного контента и решения.
- `.omx/plans/` - утверждённый план производства материалов.

## Git hooks

Папка `.githooks/` содержит быстрый локальный hook для проверки. После инициализации репозитория подключите его командой:

```bash
git config core.hooksPath .githooks
```

Hook не использует сеть и запускает только `npm run check`.

## Состояние комплекта

Переработка учебных материалов не завершена. Текущие PPTX и DOCX в `lessons/output/` являются черновиками и ещё не соответствуют требованиям курса. Подробности и оставшиеся задачи: `docs/WORK-IN-PROGRESS.md`.
