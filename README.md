# Лаборатория Питона

Учебный комплект для 5–6 классов: восемь занятий Python по 45 минут, космический сайт, презентации и Word-пособия.

## Запуск без Docker

Нужен Node.js 22 или новее. Из корня проекта:

```sh
npm start
```

Python: http://localhost:8080/python/, кабинет: http://localhost:8080/python/teacher/. Java: http://localhost:8080/java/, кабинет: http://localhost:8080/java/teacher/. Код по умолчанию — **lesson**. Дополнительные npm-зависимости не нужны. Остановка: Ctrl+C.

В Windows PowerShell при запрете запуска npm.ps1 используйте `npm.cmd start`, `npm.cmd run check` и `npm.cmd run sync:site`. Менять системную политику выполнения скриптов не требуется. После установки Node.js откройте новый терминал.

Собственные коды заменяют значение по умолчанию. В PowerShell:

```powershell
$env:TEACHER_CODES='мой-код,второй-код'
npm start
```

Не записывайте реальные коды в Git. В новой консоли переменную нужно задать заново. `.env.example` содержит настройки для Compose; `npm start` читает окружение, а `.env` автоматически не загружает.

## Docker и размещение

```sh
docker compose up --build -d
```

Откройте http://localhost:8080/. Остановка: `docker compose down`. После изменения файлов нужна пересборка. Настройки можно сохранить в локальном `.env`, скопировав `.env.example`; этот файл исключён из Git.

Для HTTPS за обратным прокси задайте `PUBLIC_ORIGIN=https://ваш-домен` и `COOKIE_SECURE=true`. Порт по умолчанию 8080. `PORT` меняет внешний порт Compose или порт локального Node.js. При HTTP cookie Secure не включается.

В этой рабочей среде Windows запущена в QEMU без аппаратной виртуализации. Локально используется Node.js. Docker Desktop требует подходящего хоста и WSL2 и не является обязательным для разработки.

**Не раздавайте корень проекта через python http.server или прежний статический Nginx:** они обходят проверку доступа к материалам. `docker/nginx.conf` оставлен как исторический файл и не используется Dockerfile.

## Поведение сайта

- Восемь последовательных миссий, три вопроса в каждой и одна деталь робота за миссию.
- Подробные объяснения, код, вывод и практика в VS Code.
- Искра и оформление Генезис-X: исходный робот с основного сайта, локальные шрифты Onest/Unbounded, космическая композиция. Пытик остаётся собираемым героем уроков.
- Светлая и тёмная темы с сохранением выбора; системная тема при первом посещении.
- Знакомство при первом посещении и повторный запуск через «Помощь».
- Локальное сохранение прогресса и восстановление незавершённого вопроса.
- Вход преподавателя по коду, сессия на восемь часов и защищённое скачивание.

Прогресс остаётся в браузере. Сессии завершаются при перезапуске сервера. Слово `lesson` служит общим доступом; для закрытых материалов задайте собственные коды и HTTPS.

## Опубликованные материалы

В `lessons/output/` опубликованными считаются:

- `lesson-01-presentation.pptx` … `lesson-08-presentation.pptx` — по 18 редактируемых слайдов с заметками преподавателя.
- `lesson-01-teacher-script.docx` … `lesson-08-teacher-script.docx` — сценарии с таймингом, объяснениями, вопросами и решениями.
- `new-learning-guide.docx` — пособие ученика.
- `scientific-methodical-guide.docx` — единое научно-методическое пособие с 11 авторскими схемами, методикой, архитектурой, восемью темами, программами, решениями, ответами, планированием и полными сценариями 144 слайдов. Включает содержание с номерами страниц, подписи и список источников; базовое оформление следует положениям ГОСТ 7.32–2017.

Файлы с суффиксами `preview`, `visual-candidate` и `v2` — прежние черновики, сервер их не публикует. PNG/PDF проверки находятся в исключённой из Git папке `.build/`.

## Изменение и проверка

Единый источник содержания — `lessons/content/lesson-XX.json`. После правки:

```sh
npm run sync:site
npm run check
```

Для исполнения примеров нужен Python 3. `PYTHON` переопределяет путь: например, `$env:PYTHON='C:/путь/python.exe'`. Проверка сверяет генерацию сайта и запускает тесты доменных правил, миграции прогресса, настроек, HTTP-доступа и программ Python. Интерфейс проверяется также в браузере.

Сборка документов описана в `lessons/scripts/README.md`. Архитектура, API и результаты аудита находятся в `docs/`. Изменения в локальном репозитории не обновляют внешний сервер автоматически: для публикации нужны доступ к размещению и пересборка контейнера.

Проверка интерфейса и размещения от 12.11.2026: [docs/SITE_AUDIT.md](docs/SITE_AUDIT.md). Подтверждённые исправления и оставшиеся условия безопасного выпуска: [security_best_practices_report.md](security_best_practices_report.md).

## Java для 10–11 классов

Добавлен самостоятельный курс «Орбита Java»: /java/ после npm start. 10 занятий по 90 минут, 30 вопросов, интерактивная карта, 10 PPTX по 15 слайдов, 10 сценариев Word и сводное иллюстрированное научно-методическое пособие. Итоговый проект — локальный Java маршрутный центр с веб-интерфейсом и тестами. Материалы Java доступны в /java/teacher/, Python — в /python/teacher/. Старый общий кабинет /teacher/ сохранён для совместимости.

Источник, исходники и инструкции находятся в [java-course/README.md](java-course/README.md). npm run check проверяет оба курса; дополнительно требуется JDK 21. Публикация на VPS остаётся отдельным действием и не выполняется обычным Git push.

## Внедрение под одним адресом

Курсы размещаются в разных путях одного origin: `/python/` и `/java/`, без поддоменов и переходов друг к другу. Для основного сайта достаточно двух отдельных ссылок. Каждый кабинет преподавателя показывает только материалы своего курса. Прогресс и учебное содержание независимы. Инструкция обновления сервера и точные пути: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
